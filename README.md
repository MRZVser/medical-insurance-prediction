# medical-insurance-prediction
# Прогнозирование стоимости медицинских страховок (Medical Cost Personal Dataset)

# Описание проекта
Данный проект разрабатывается в рамках практических занятий по интеллектуальным системам. Основная задача — построение модели машинного обучения для предсказания индивидуальных медицинских расходов пациентов на основе их демографических и физических характеристик. Проект включает этапы предварительной обработки данных (EDA), работу с признаками, обучение регрессионных моделей и оценку их точности.

# Цель
Разработать и оптимизировать модель регрессии для прогнозирования целевой переменной charges.
Задача заключается в том, чтобы минимизировать ошибку предсказания и определить, какие факторы (например, курение или индекс массы тела) вносят наибольший вклад в итоговую стоимость страхового полиса.
# Источник данных
В работе используется набор данных Medical Cost Personal Dataset. Выборка содержит информацию о клиентах страховой компании в США.

Признаки (X):
Age — Возраст основного бенефициара (годы).
Sex — Пол пациента (female, male).
BMI — Индекс массы тела ($кг / м^2$), позволяющий оценить степень соответствия массы человека и его роста.
Children — Количество детей / иждивенцев, охваченных медицинской страховкой.
Smoker — Статус курения (yes, no).
Region — Район проживания бенефициара в США (northeast, southeast, southwest, northwest).

Целевая переменная (y):Charges — Индивидуальные медицинские расходы, оплачиваемые медицинской страховкой (в долларах США).
